# French-suited card artwork

The SVG card faces and back in this directory come from
`MattCain/svg-playing-cards`, distributed under the MIT License and derived
from the public-domain Vector Playing Cards artwork.

- source: https://github.com/MattCain/svg-playing-cards
- license: https://github.com/MattCain/svg-playing-cards/blob/master/LICENSE

The files are vendored locally so a self-hosted Sala13 server does not contact
an external image service during a match.
